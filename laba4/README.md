## 1. Хипуй!

В этой задаче необходимо организовать структуру данных `Heap` для хранения целых чисел, над которой определены следующие операции:

- `Insert(k)` — добавить в `Heap` число `k` (`1 ≤ k ≤ 1 000 000`).
- `Extract` — извлечь из `Heap` наибольшее число и удалить его из структуры.

### Входные данные

В первой строке содержится количество команд `N` (`1 ≤ N ≤ 100 000`). Далее следуют `N` команд, каждая на отдельной строке.

Команда может иметь один из следующих форматов:

- `0 <число>` — выполнить операцию `Insert(<число>)`.
- `1` — выполнить операцию `Extract`.

Гарантируется, что при выполнении команды `Extract` в структуре находится хотя бы один элемент.

### Выходные данные

Для каждой команды `Extract` выведите отдельной строкой число, полученное в результате операции.

### Пример

**Входные данные:**
```text
2
0 10000
1
```

**Выходные данные:**
```text
10000
```

## 3. Пирамида (минимум)

Задача отличается от задачи «Пирамида (максимум)» только тем, что требуется извлекать не максимальный, а минимальный элемент.

Напишите программу, которая обрабатывает последовательность запросов следующих типов:

- `CLEAR` — очистить пирамиду. Если в ней уже есть элементы, удалить их все. Операция изменяет только данные в памяти и ничего не выводит на экран.
- `ADD n` — добавить в пирамиду число `n`. Операция изменяет только данные в памяти и ничего не выводит на экран.
- `EXTRACT` — извлечь минимальный элемент. Если пирамида не пуста, удалите элемент и выведите его значение. Если пирамида пуста, выведите слово `CANNOT` (заглавными буквами).

### Входные данные

Дана произвольная последовательность запросов `CLEAR`, `ADD` и `EXTRACT`. Каждый запрос записан на отдельной строке.

Суммарное количество запросов не превышает `200 000`.

### Выходные данные

Для каждого запроса `EXTRACT` выведите результат отдельной строкой.

### Пример

**Входные данные:**
```text
ADD 192168812
ADD 125
ADD 321
EXTRACT
EXTRACT
CLEAR
ADD 7
ADD 555
EXTRACT
EXTRACT
EXTRACT
```

**Выходные данные:**
```text
125
321
7
555
CANNOT
```

## 5. Коммерческий калькулятор

Фирма OISAC выпустила новую версию калькулятора. Этот калькулятор берет с пользователя деньги за выполняемые арифметические операции. Стоимость каждой операции составляет 5% от числа, являющегося результатом этой операции.

На калькуляторе требуется вычислить сумму `N` натуральных чисел, значения которых известны. От порядка сложения зависит общая стоимость вычисления суммы.

Во второй строке заданы `N` натуральных чисел, каждое из которых не превосходит `10 000`.

### Выходные данные

Выведите минимальную стоимость вычисления суммы с точностью до двух знаков после десятичной точки.

### Пример

**Входные данные:**
```text

10 11 12 13
```

**Выходные данные:**
```text

```

## 6. Таможня

Идёт 2163 год. Миша работает в отделении таможни при космодроме города Нью-Питер. Однажды его вызывает начальник.

Министерство налогов и сборов выделило отделению деньги на установку новых аппаратов для автоматического досмотра грузов. Средства рассчитаны так, чтобы грузы находились на таможне ровно столько времени, сколько необходимо для их досмотра.

Начальнику стал известен список из `N` грузов, которые будут контролироваться Министерством. Для каждого груза известны время прибытия и время, необходимое для его обработки.

Мише поручено определить минимальное количество аппаратов, которое нужно заказать, чтобы каждый груз начинали досматривать сразу после прибытия.

Один аппарат не может обрабатывать два груза одновременно.

### Входные данные

В первой строке задано число `N` (`0 ≤ N ≤ 50 000`).

В следующих `N` строках указаны по два целых положительных числа `Tᵢ` и `Lᵢ`:

- `Tᵢ` — время прибытия груза;
- `Lᵢ` — время, необходимое для его обработки.

Гарантируется, что `1 ≤ Tᵢ ≤ 10⁶` и `1 ≤ Lᵢ ≤ 10⁶`.

### Выходные данные

Выведите минимальное количество аппаратов, необходимое для обработки всех грузов без ожидания.

### Пример

**Входные данные:**
```text
3
3 2
4 2
5 2
```

**Выходные данные:**
```text
2
```

## 7. Вычислительная ихтиология

Игорь работает младшим лаборантом в НИИ ихтиологии. Ему вверены `n` аквариумов, стоящих в ряд. В каждом аквариуме живёт колония рыбок гуппи, численность которой известна заранее.

В лабораторных условиях колония численностью `f` рыбок растёт по следующему правилу: достигнув численности `f`, она живёт в течение

`max(1000 − f, 1)`

секунд, после чего рождается новая рыбка.

От начального момента времени до рождения первой рыбки колония также ждёт `max(1000 − f, 1)` секунд.

Например, колония с начальной численностью `996` размножается следующим образом:

| Время (секунды) | Численность колонии | Время до следующего рождения (секунды) |
|---:|---:|---:|
| 0 | 996 | 4 |
| 4 | 997 | 3 |
| 7 | 998 | 2 |
| 9 | 999 | 1 |
| 10 | 1000 | 1 |
| 11 | 1001 | 1 |
| 12 | 1002 | 1 |

Рождение каждой новой рыбки Игорь должен фиксировать в специальном журнале. Считается, что запись делается мгновенно, но в момент рождения рыбки Игорь должен находиться рядом с соответствующим аквариумом.

На перемещение от одного аквариума к соседнему уходит одна секунда. В начальный момент времени Игорь стоит около первого аквариума.

Определите, в какой момент времени родится первая рыбка, запись о рождении которой Игорь не сможет сделать.

### Входные данные

В первой строке задано целое число `n` (`2 ≤ n ≤ 50`) — количество аквариумов.

Каждая из следующих `n` строк содержит одно целое число `aᵢ` (`1 ≤ aᵢ ≤ 2007`) — начальную численность колонии в соответствующем аквариуме.

### Выходные данные

Выведите момент времени, когда родится первая рыбка, рождение которой Игорь не сможет зафиксировать.

### Пример

**Входные данные:**
```text
3
996
1
994
```

**Выходные данные:**
```text
7
```
